How to run it
  1. Pair the D10 to the phone in Android Bluetooth settings and make sure it says Connected.
  2. Open this page in Chrome, then tap Start probe.
  3. Press the button the page asks for. Hold the remote close — one press per prompt.
  4. If nothing registers within a few seconds, tap Nothing happened and continue.
  5. Tap Copy report at the end and paste the result back into the chat.
